## Headline shifts

- **Authoring agency rotates each drop** — DoW share R1 50% / R2 81% / R3 17% / R4 70% / R5 46%; FBI R1 36% / R2 0% / R3 40% / R4 2% / R5 41%; CIA R1 0% / R2 2% / R3 25% / R4 5% / R5 5%. R1 led with DoW+FBI, R2 was a near-pure DoW video dump, R3 swung to FBI+CIA (adding ICA and USG), R4 tilted back toward DoW with a fresh NASA/DoE contingent, and R5 splits almost evenly between DoW and FBI - the narrowest gap between the two in any drop - while adding EOP (Executive Office of the President).
- **Geography: CENTCOM → CONUS → maritime/Pacific** — CENTCOM/Middle-East share R1 33% / R2 50% / R3 0% / R4 5% / R5 27%; CONUS R1 20% / R2 20% / R3 56% / R4 48% / R5 34%; INDOPACOM/Pacific R1 3% / R2 6% / R3 0% / R4 15% / R5 12%. R1/R2 were Gulf-war-zone heavy, R3 pivoted to the US homeland, R4 broadened toward maritime and Pacific (East/South China Sea, Yellow Sea, Atlantic), and R5 splits between the Gulf of Oman / Pacific clip runs and a CONUS FBI caseload, while reopening the Latin-America lane dormant since R1 (Bahia, Brazil 1963).
- **Redaction & the Featured flag** — Redacted share R1 66% / R2 84% / R3 17% / R4 48% / R5 34%. Featured hero records: R1 0, R2 0, R3 10, R4 10, R5 9. The Featured flag (debuted in R3) continues in R5; redaction rate tracks composition (already-declassified historical files vs contemporary casework).
- **Asset mix swings document ↔ video each drop** — PDF share R1 73% / R2 9% / R3 74% / R4 35% / R5 54%; video R1 17% / R2 80% / R3 8% / R4 48% / R5 39%. R2 and R4 are the video-heavy drops (raw DVIDS clips); R1, R3 and R5 are paper-heavy. R5 adds 16 new clips alongside 22 documents.
- **Historical reach: 1950s-60s and the space program** — 1950s incidents R1 3% / R2 0% / R3 18% / R4 10% / R5 2%; 1960s R1 6% / R2 9% / R3 15% / R4 2% / R5 10%. R3 opened the CIA Cold-War lane and the Mercury/Gemini NASA expansion; R4 continued the NASA thread (Apollo 14, STS-80 shuttle) and added DoE Los Alamos conference material; R5 reaches back to the 1947 'Ghost Rocket' intelligence review and pairs 1963 State Department cables with an Executive Office inquiry into the same Brazilian incident.
- **Object morphology across the five drops** — sphere/orb R1 13% / R2 2% / R3 21% / R4 12% / R5 7%; disc R1 17% / R2 2% / R3 24% / R4 22% / R5 2%; circular R1 36% / R2 3% / R3 25% / R4 28% / R5 7%; triangle R1 7% / R2 0% / R3 7% / R4 2% / R5 2%. Descriptive morphology is richest in the document-heavy drops (R1, R3) and thinnest in the video-heavy ones (R2, R4), whose signal lives mostly in clip titles. These tags are scanned from document bodies only, so R5 reads low despite an FBI batch explicitly about triangles: its renderings are image-only PDFs, and the morphology sits in the titles, not the text.
